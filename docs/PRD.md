# ListenUp 상세 PRD

> 2026-09-09 변경: 로컬 Whisper/Qwen 구현은 OpenAI API 전사·요약으로 대체되었다. 현재 동작과 검증 기준은 [OpenAI API 전환 문서](OPENAI_API_MIGRATION.md)를 우선한다. 아래 로컬 모델 내용은 초기 결정 기록이다.

문서 버전: 1.2 · 작성일: 2026-09-09 · 상태: 네이티브 구현 및 통합 검증 진행 중

## 1. 제품의 목적

사용자가 강의와 회의 내용을 놓치지 않도록 Mac에서 오디오를 녹음하고, 전체 내용을 전사한 뒤 목적에 맞게 정리한다. 사용자는 결과를 확인·수정하고 노션에 복사하거나 Finder에서 파일을 직접 관리한다.

핵심 완료 흐름은 **녹음 또는 파일 가져오기 → 전체 전사 → 강의/회의 요약 → 확인 → 복사 또는 폴더 열기**다. 데이터베이스·계정·자체 서버 없이 개인용으로 시작한다.

‘전체 내용’은 캡처된 음성 전체를 처리 대상으로 삼는다는 뜻이다. STT의 100% 정확성, 동시에 말한 모든 단어의 복원, 실제로 캡처되지 않은 구간의 복원을 보장하지 않는다. 누락·실패 구간을 숨기지 않아야 한다.

## 3. 대표 사용자 여정

### 3.1 온라인 강의

1. ‘새 녹음’에서 강의, 제목, 한국어, 강의가 재생되는 앱을 선택한다. 마이크는 기본 꺼짐이다.
2. 강의명·전문용어를 선택적으로 입력하고 입력 레벨을 확인한다.
3. 녹음을 시작한다. 들었던 내용을 복습할 때 앱에서 ‘15초 뒤로’를 누르거나 강의 플레이어에서 되감는다.
4. 외부 플레이어를 되감았다면 ‘다시 듣는 구간 표시’를 켰다가 새 내용으로 돌아왔을 때 끈다. 이 표시는 녹음을 중단하지 않는다.
5. 종료 후 전체 전사와 강의 요약이 생성된다. 반복 제외 범위를 확인하고 요약을 갱신한다.
6. ‘요약 복사’, ‘전체 전사 복사’, ‘요약+전체 복사’로 노션에 붙여 넣는다.

### 3.2 온라인·대면 회의

1. 회의를 선택한다. 온라인은 회의 앱 오디오+마이크, 대면은 마이크만 선택한다.
2. 안건·참석자 이름·프로젝트 용어를 선택적으로 입력한다.
3. 녹음 중 북마크와 개인 메모를 남긴다. 메모는 실제 발언과 구분한다.
4. 종료 후 안건별 논의, 확정 결정, 실행 항목, 미결 사항을 확인한다.
5. 담당자·기한을 알 수 없으면 ‘미정’으로 표시한다. 참석자 명단으로 발언자를 임의 지정하지 않는다.

### 3.3 보유한 강의 파일

파일을 가져와 원본 시간축으로 한 번 전사한다. 앱 플레이어에서 같은 구간을 여러 번 들어도 파일 전사는 재실행하지 않는다. 이 방식은 외부 강의 되감기로 생기는 중복을 가장 확실하게 피할 수 있다. URL 다운로드나 보호된 강의 추출은 MVP 범위가 아니다.

## 4. 범위와 출시 단계

| 기능 | MVP / P0 | 후속 / P1 |
| --- | --- | --- |
| 녹음 | 마이크, 선택 앱의 시스템 오디오, 둘 모두 | 추가 앱별 캡처 호환성 확대 |
| 입력 파일 | 로컬 m4a/mp3/wav, AVFoundation으로 디코드 검증 | 추가 컨테이너·배치 가져오기 |
| 전사 | 종료 후 전체 처리, 구간별 진행률, 실패 재시도 | 녹음 중 준실시간·실시간 전사 |
| STT | WhisperKit 로컬 adapter와 테스트용 mock | 다른 로컬 공급자 추가 |
| 다시 듣기 | 앱 내부 과거 구간 재생, 외부 반복 구간 수동 표시 | 반복 후보 자동 탐지, 특정 플레이어 시간 연동 |
| 회의 화자 | 입력 출처 표시, 발언자 미상 허용, 수동 이름 편집 | 실제 화자 분리·구간 간 동일인 확인 |
| 요약 | 강의·회의 템플릿, 근거 구간, 요약 길이, 수정·재생성 | 사용자 템플릿, 여러 결과 비교 |
| 저장·내보내기 | 로컬 폴더, md/txt/json, 일반 복사·서식 복사 | 자막, 일괄 내보내기 |

MVP 전사는 로컬 WhisperKit, 요약은 Qwen3 4B MLX 4bit로 진행한다. 모델 설치와 두 로컬 adapter를 P0로 포함하고 클라우드 경로 및 자동 fallback은 구현하지 않는다.

제외 범위: 노션 API 자동 저장, 로그인·구독 결제, 팀 공유, 서버 업로드 보관, 벡터 DB, 전체 세션 검색 서비스, 회의 참여 봇, 화면 영상 저장, Windows, 브라우저 확장, DRM 우회, 자동 실명 화자 인식.

## 6. 되감기에 대한 제품 계약

| 상황 | 저장·전사 동작 | 사용자에게 알릴 내용 |
| --- | --- | --- |
| ListenUp에서 과거 녹음 재생 | 기존 녹음 파일을 읽음. 캡처는 현재 입력을 계속 저장 | 현재 라이브 소리와 복습 소리가 겹칠 수 있음. 이어폰과 외부 강의 일시정지 사용 가능 |
| 브라우저 강의 되감기 | 되감아 재생된 소리도 새 시각에 다시 녹음 | 원 강의 재생 위치는 모름. 반복 표시를 직접 지정 |
| 브라우저 강의 앞으로 건너뛰기 | 재생되지 않은 부분은 캡처할 수 없음 | 누락된 원 강의 내용을 복원한다고 표시하지 않음 |
| 가져온 파일 되감기 | 원본 파일은 한 번만 전사, 재생 위치와 무관 | 원본 파일 기준 타임스탬프 사용 |
| 강의 배속 변경 | 캡처된 배속 음성을 그대로 전사 | 원 강의 시간과 녹음 시간이 다름. 고배속 정확도 별도 검증 |

‘중복 제거’라는 이름으로 전사문을 자동 삭제하지 않는다. 반복 발언은 강조·정정·동의일 수 있다. 사용자가 지정한 구간을 요약에서 제외하되, 제외된 시간 범위를 결과 상단에 표시한다. 회의에서는 반복 구간 표시가 기본 꺼짐이며 동일 문장을 재발언했다고 자동 합치지 않는다.

본인 앱의 소리를 시스템 캡처에서 제외해 디지털 재녹음을 막는다. 스피커 소리가 마이크에 들어오는 음향 누출까지 막는 것은 아니므로, 마이크 동시 녹음 중 다시 듣기는 이어폰 환경을 먼저 지원·검증한다. 외부 앱의 재생·볼륨은 자동 조작하지 않는다.

## 7. 화면 구성

### 최초 실행·모델 설치

앱 설치 파일에는 추론 라이브러리만 포함하고 모델 가중치는 포함하지 않는다. 최초 실행에서 전사 모델(Whisper 626,718,238 bytes)과 요약 모델(Qwen3 4B 4bit runtime assets 2,278,969,756 bytes)의 용도·다운로드 용량·저장 위치를 표시한다. 값은 고정 revision의 manifest 기준이다.

‘필요한 모델 모두 받기’, 모델별 ‘다운로드’, ‘나중에’ 동작을 제공한다. 진행률과 받은 용량을 표시하고 일시정지·재개·취소·실패 재시도를 지원한다. 앱 재실행 후에도 완료된 파일을 재사용한다. 다운로드만 끝났다고 준비 완료로 표시하지 않고 무결성 검사와 로딩 검증을 완료한다.

모델 미설치 상태에서도 녹음·저장·다시 듣기는 가능하다. 전사 모델만 있으면 전체 전사까지 가능하고 요약은 모델 설치 대기로 표시한다. 두 모델 설치 후에는 인터넷 없이 전사·요약이 가능해야 한다. 모델을 설치하는 과정에서 녹음이나 전사문을 전송하지 않는다.

설정의 ‘모델 관리’에서 설치 상태·용량·위치·삭제를 제공한다. 모델 삭제는 녹음·전사·요약 파일을 삭제하지 않는다. 앱 업데이트는 호환되는 기존 모델을 재사용하고 모델 업데이트는 별도 동작으로 제공한다. 기본 모델은 Qwen3 4B이며 8B는 자동 설치하지 않는다.

### 새 녹음

제목 / 강의·회의 선택 / 입력 소스 / 마이크 선택 / 언어 / 추가 문맥 / 저장 폴더 / 녹음 시작. 기본 화면에는 필요한 항목만 표시하고 공급자·모델·상세 문맥은 펼칠 수 있게 한다. 권한이 없으면 해당 입력 옆에 해결 동작을 제공한다.

### 녹음 중

상단: 제목, 녹음 상태, 경과 시간, 소스별 레벨, 디스크 상태. 중앙: 타임라인·북마크·개인 메모. 하단: 녹음 일시정지/종료와 재생 뒤로/재생 정지/실시간 위치를 서로 다른 그룹으로 배치한다. ‘녹음 일시정지’와 ‘다시 듣기 정지’의 텍스트·아이콘을 구별한다.

MVP에는 실시간 자막을 약속하지 않는다. ‘녹음 종료 후 전사합니다’와 저장된 길이를 보여준다. 확정된 과거 오디오는 최대 약 5초 늦게 다시 들을 수 있는 설계 목표다.

### 처리·결과

진행률은 파일 확정→전사 N/M 구간→요약 순으로 표시한다. 실패 구간과 재시도 버튼을 제공한다. 결과 화면은 전체 전사/요약 탭, 근거 구간 재생, 편집, 목적 변경, 요약 재생성, 세 가지 복사 버튼, 폴더 열기로 구성한다.

### 설정

저장 위치, 로컬 모델 설치·삭제, 기본 언어, 녹음 후 자동 처리, 원본 오디오 보존을 관리한다. 원본 오디오는 기본 보존한다. 사용자가 삭제하면 다시 듣기·재전사가 불가능함을 해당 동작에서 안내한다.

## 8. 출력 형식

### 강의 요약

제목·녹음 정보 → 핵심 요약 → 주제별 설명 → 주요 개념·정의 → 예시·절차 → 강사가 강조한 사항 → 복습 질문 → 불명확한 부분 → 요약 제외 구간.

복습 질문은 원문에서 파생한 학습 보조물로 표시한다. 원문에 없는 설명을 강사의 발언으로 쓰지 않는다. 지시어나 화면 설명만 있는 구간은 ‘화면 자료 확인 필요’로 표시한다.

### 회의 요약

제목·일시·참석자(입력값) → 안건별 논의 → 확정 결정 → 실행 항목 → 미결 사항·이견 → 다음 회의 관련 발언 → 불명확한 부분.

실행 항목은 업무 / 담당자 또는 미정 / 기한 원문 또는 미정 / 상태 / 근거 구간을 갖는다. ‘검토해보자’를 확정 결정이나 완료된 업무로 바꾸지 않는다. 상대 날짜는 원문을 보존하고, 날짜를 계산하는 경우 세션의 시간대와 기준일을 함께 남긴다.

### 전체 전사

제목·날짜·입력·모델·시간 기준 → 시간순 전사 구간. 편집한 경우 ‘교정본’ 표시와 원본 파일 제공. 캡처 중단·일시정지·처리 실패는 본문에 상태 구간으로 남긴다. 사용자 메모는 별도 절에 표시한다.

## 9. 비기능 요구와 출시 기준

아래 수치는 측정 전의 목표이며 제품 성능에 대한 실측 주장이 아니다. 기준 환경은 현재 확인한 M1 Pro, RAM 16GiB, macOS 26.6.2, 로컬 SSD로 한다. 최소 지원 OS인 macOS 15도 별도 검증한다. 클라우드와 로컬 추론의 자원·후처리 목표는 구분한다.

| 항목 | 목표와 검증 방식 |
| --- | --- |
| 장시간 녹음 | 2시간 시스템+마이크 녹음에서 앱 원인 무표시 누락 0건. 입력 공백은 Gap으로 기록 |
| 복구 범위 | 정상 확정된 5초 조각은 모두 복구. 강제 종료 시 마지막 미확정 조각은 최대 약 5초 손실 목표 |
| 오디오 동기 | 2시간 테스트 신호에서 시스템·마이크 상대 오차 100ms 이내 목표 |
| 메모리 | 클라우드 모드 2시간 세션 RSS 500MB 이하 목표, 시간에 비례하는 무제한 메모리 증가 없음 |
| UI 반응 | 녹음 제어·타임라인 조작 p95 200ms 이내 목표, 긴 전사 목록은 가상화 |
| 후처리 | 60분 녹음의 종료 후 전사+요약 10분 이내 목표. 네트워크·API 지연 및 선택 모델별 실측 필요 |
| 로컬 추론 | 위 500MB 메모리·10분 후처리 목표는 클라우드 모드 기준. 로컬은 STT/4B별 4/6GB 자원 예산, 60분 입력의 전사+요약 25분 내 잠정 목표를 별도 시험 |
| 전사 품질 | 별도 평가 계획의 한국어 CER·고유명사·수치 평가 통과. 품질 미달을 요약 모델로 숨기지 않음 |
| 요약 신뢰성 | 평가 세트에서 확정 결정/담당자/기한의 근거 없는 생성 0건, 중요 항목 누락 기준 통과 |
| 휴대성 | 앱이 없어도 md/txt를 읽을 수 있음. 폴더 이름 변경이 내부 상대 경로를 깨뜨리지 않음 |
| 접근성 | 키보드 탐색, VoiceOver 레이블, 상태를 색상만으로 구분하지 않음 |

절전·덮개 닫힘 동안 지속 녹음을 보장하지 않는다. 가능한 종료·중단 이벤트를 기록하고 재개 여부를 표시한다. OS 권한 철회, 장치 이탈, 보호된 콘텐츠의 무음은 실제 기기 시험 대상으로 남긴다.

## 10. 완료 판정과 연계 문서

MVP 완료는 정상 경로 데모만으로 판정하지 않는다. 녹음 중 다시 듣기, 외부 30초 되감기, 네트워크 단절 후 재처리, 앱 강제 종료 후 복구, 노션 복사, 폴더 이동 후 재열기를 모두 확인해야 한다.
