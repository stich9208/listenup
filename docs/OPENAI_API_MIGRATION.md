# OpenAI API 전환

상태: 구현 완료  
결정일: 2026-09-09

## 결정

M1 Pro 16GiB에서 로컬 Whisper 전사와 Qwen 요약의 처리 시간과 메모리 사용량이 실제 사용에 적합하지 않아, 전사와 요약을 OpenAI API로 전환한다. 녹음, 재생, 리비전, 내보내기와 세션 저장 구조는 유지한다.

| 기능 | 기본 모델 | 선택 모델 | API |
| --- | --- | --- | --- |
| 전사 | `gpt-transcribe` | `gpt-4o-mini-transcribe` | `POST /v1/audio/transcriptions` |
| 요약 | `gpt-5.6-luna` | `gpt-5.6-terra` | `POST /v1/responses` |

## 처리 흐름

1. 앱은 API 키를 macOS 키체인에 저장한다. 키는 UserDefaults, 세션 JSON, 로그에 저장하지 않는다.
2. 녹음 파일은 사용자가 고른 세션 폴더에 그대로 보존한다.
3. 전사가 필요하면 오디오를 60초 단위 16kHz mono PCM WAV로 변환해 순차 전송한다.
4. 세션 용도(강의 또는 회의), 언어, 전문 용어, 추가 문맥을 전사 요청에 함께 보낸다.
5. 각 전사 응답은 원본 시간 범위와 OpenAI request ID를 연결해 리비전으로 먼저 저장한다.
6. 완전한 전사 리비전이 있으면 이를 재사용하고 STT를 다시 호출하지 않는다.
7. 요약은 용도별 JSON 계약으로 요청하고, 응답의 근거 segment ID를 로컬에서 검증한 뒤 저장한다.
8. 전체 전사, 요약, 합본 Markdown을 `exports/`에 기록한다.

## UI 상태

- API 키가 없으면 전사와 요약 버튼을 비활성화하고 같은 결과 화면에 필요한 조치를 표시한다.
- 연결 확인은 API 키 인증을 별도로 검사한다.
- 진행 상태는 전사 청크 수와 요약 단계를 구분해 표시한다.
- 전사가 완료된 세션에서는 주 처리 버튼을 `전사 완료`로 비활성화하며, 요약 생성과 재생성만 제공한다.
- 오류는 HTTP 인증, 권한, 모델 없음, 파일 크기, 사용량 제한, 서버 오류, 네트워크 오류를 한국어로 구분한다.

## 개인정보와 저장

오디오와 전사문은 OpenAI API 처리에 전송된다. Responses API 요청은 `store: false`를 지정한다. 세션 원본과 결과의 장기 보관 위치는 사용자가 선택한 로컬 폴더이며 ListenUp 자체 서버나 별도 데이터베이스는 없다.

## 검증

- 단위 테스트에서 Authorization 헤더, multipart 모델·언어·키워드·WAV 데이터, Responses API의 `store: false`, 응답 파싱을 모의 URLSession으로 검사한다.
- 저장된 완전한 전사의 재사용 조건을 확인한다.
- 배포 빌드가 WhisperKit, MLX, 모델 bundle과 Metal shader를 포함하지 않는지 검사한다.
- 실제 API 통합 검증은 사용자가 자신의 키를 키체인에 저장한 뒤 앱의 연결 확인과 짧은 한국어 샘플로 수행한다.
