# STT·요약 모델 선택 및 비용 검토

작성일·가격 확인일: 2026-09-09. 유료 API 호출은 수행하지 않았다. 고정 로컬 가중치로 합성 한국어 음성 통합 smoke를 실행했지만 실제 강의·회의 품질 벤치마크는 아직 수행하지 않았다. 공식 문서의 지원 기능, 짧은 smoke, 설계 판단을 구분한다.

## 1. 권장 선택

사용자는 **로컬 전사로 진행**하기로 선택했다. M1 Pro 16GiB에서 WhisperKit의 실제 모델 설정을 평가하고, 요약은 Qwen3 4B MLX 4bit를 기본 검증 후보로 선택한다. 사용자의 설치 용량·RAM 우려를 반영해 8B는 기본 설치 및 초기 평가에서 제외한다. 다음 클라우드 권고는 클라우드 사용을 선택했을 때의 조건부 후보이며 기본 확정이 아니다. 로컬 용량·메모리·성능 검토는 [로컬 모델 문서](LOCAL_MODELS_AND_HARDWARE.md)에 상세히 작성했다.

클라우드 허용 시 **GPT-Transcribe를 균형형 1차 후보**, **GPT-4o mini Transcribe를 저비용 비교 후보**로 선정한다. 현재 OpenAI 파일 전사 가이드도 일반 녹음에 GPT-Transcribe를 권장하지만, 이것만으로 사용자의 한국어 강의에서 최고 정확도라는 결론은 내릴 수 없다. [OpenAI 파일 전사](https://developers.openai.com/api/docs/guides/speech-to-text)

화자 분리와 실시간 전사가 중요해지면 Deepgram Nova-3를 비교한다. 음성을 외부로 보낼 수 없으면 WhisperKit의 다국어 모델을 실제 Mac에서 평가한다. 요약 모델은 STT와 독립적으로 선택한다.

사용자에게 ‘균형형 / 저비용 클라우드 / 화자 구분·실시간 확장 / 로컬형’ 후보를 제시했고, 사용자는 로컬 성능·하드웨어 요구를 먼저 확인하고 싶다고 답했다. 따라서 모델 확정은 후속 평가 작업으로 남기고, 네 공급자를 전부 MVP로 구현하지 않는다.

## 2. STT 비용 비교

USD, 단일 오디오 스트림, 재처리·겹침 없음, STT만의 예상 비용이다. 세금·환율·요약·모델 다운로드·장치 비용은 제외한다. OpenAI의 분당 수치는 공식 예상치이며 실제 청구는 모델별 사용량에 따라 달라질 수 있다. 시간·월 금액은 분당 값에서 산출했다.

OpenAI 단가는 [공식 가격표](https://developers.openai.com/api/docs/pricing), Nova-3는 Pay As You Go의 Pre-Recorded 가격을 사용했다. Nova-3 파일 전사는 화자 분리가 포함되어 있고 용어 강조 등의 추가 기능은 별도다. 실시간 단일 언어는 현재 프로모션 $0.0048/분, 화자 분리 추가 $0.0020/분으로 합계 $0.408/시간이며, 프로모션 종료 후 가격 재확인이 필요하다. [Deepgram 가격·추가 기능](https://deepgram.com/pricing)

Deepgram의 한국어는 `ko` 또는 `ko-KR`로 지정할 수 있다. 그러나 Nova-3 `multi` 목록에는 현재 한국어가 명시되어 있지 않으므로, 한국어+영어 혼용 강의에 `multi`를 자동 선택하지 않는다. `ko` 조건에서 영문 전문용어 인식을 직접 평가한다. [모델별 언어 목록](https://developers.deepgram.com/docs/models-languages-overview)

화자 전용 후보인 GPT-4o Transcribe Diarize는 일반 전사와 별도 옵션이다. 모델 페이지에서 100만 오디오 토큰당 입력 $2.50, 출력 $10.00을 확인했으나, 이번에 조회한 종합 가격표에는 이 모델의 분당 예상값이 없어 위 표의 시간당 비교에서 제외했다. 과거의 분당 수치를 현재 확정 단가로 사용하지 않는다. [Diarize 모델](https://developers.openai.com/api/docs/models/gpt-4o-transcribe-diarize)

## 3. 기능과 구현 영향

| 후보 | 공식 지원·확인한 사실 | 제품에서 주의할 점 |
| --- | --- | --- |
| GPT-Transcribe | 파일 전사, prompt·keywords·languages 문맥 입력 | 기본 결과를 정확한 단어 타임스탬프로 가정하지 않는다. 업로드 구간 단위 위치 제공 |
| GPT-4o mini / GPT-4o Transcribe | 파일 전사와 prompt 지원 | 비용과 한국어 전문용어 정확도의 실측 비교 필요 |
| GPT-4o Transcribe Diarize | 화자·시작·종료가 있는 diarized_json, prompt 미지원 | 녹음 목적을 STT prompt로 전달할 수 없음. 목적은 요약 단계에 전달 |
| Nova-3 | 한국어 지원, 파일·스트리밍, 화자 분리 | 단일 요청 내 화자 번호를 여러 요청의 동일인으로 취급하지 않음 |
| WhisperKit | Apple Silicon용 온디바이스 STT, Swift 패키지, 다국어 Whisper 모델 | 최초 모델 다운로드·RAM·발열·속도·정확도 평가. 로컬 요약은 별도 필요 |

OpenAI 요청은 25MB 이하 파일로 제한하고, Diarize에서 30초 초과 요청에는 `chunking_strategy`를 지정한다. `timestamp_granularities`는 `whisper-1` 전용이므로 다른 모델에 일괄 전달하지 않는다. [파일 전사 API 제약](https://developers.openai.com/api/docs/guides/speech-to-text)

WhisperKit 저장소는 현재 Argmax OSS Swift로 연결된다. 후보는 공식 README가 제시하는 다국어 large-v3 계열이며 tiny는 디버깅용으로만 고려한다. 패키지·가중치 버전과 체크섬을 고정한 후 평가해야 한다. [Argmax 공식 저장소](https://github.com/argmaxinc/argmax-oss-swift)

위 기능은 지원 여부이고 성능 순위가 아니다. 녹음 장치, 소음, 발음, 한국어·영어 혼용, 화자 겹침, 배속, 긴 발언, 기술 용어가 실제 정확도를 좌우할 수 있다.

## 4. 강의/회의를 알려주면 무엇이 달라지는가

### STT 단계: 효과를 기대할 수 있으나 용도 이름만으로 보장하지 않는다

일반 전사는 음성에서 단어를 복원한다. ‘강의’라는 한 단어보다 ‘데이터베이스 강의, PostgreSQL, MVCC, WAL’처럼 실제 등장 용어를 주는 방식이 더 구체적인 문맥을 제공한다. GPT-Transcribe는 이러한 문맥과 언어 힌트를 받는다. [GPT-Transcribe 모델 설명](https://developers.openai.com/api/docs/models/gpt-transcribe)

설계 판단: 문맥은 철자와 동음이의어 인식에 도움을 줄 가능성이 있지만, 입력한 참석자 이름이나 전문용어를 실제 발언이 없는 곳에 삽입하는 편향도 시험해야 한다. 지원하지 않는 공급자에는 프롬프트를 보내지 않는다. ‘회의록으로 요약해’라는 지시를 STT에 전달하지 않는다.

### 요약 단계: 목적을 명시적으로 반영해야 한다

강의는 개념·설명·예시·학습 순서를, 회의는 결정·책임·기한·이견을 우선해야 한다. 따라서 `sessionPurpose`는 필수이고, 서로 다른 출력 스키마와 프롬프트를 사용한다. 이는 제품 요구에 따른 설계이며, 개선 폭의 수치 주장은 하지 않는다.

목적을 녹음 뒤 바꿔도 요약만 재생성할 수 있다. STT 문맥을 바꾸어 전사를 다시 실행하는 것은 별도 비용이 드는 명시적 동작이다. 참석자 목록은 발언 증거가 아니며, 누구의 발언인지 음성이나 사용자의 확인이 없으면 실명을 붙이지 않는다.

## 5. 요약 모델과 비용

클라우드 MVP의 잠정 기준 모델은 **GPT-4.1 mini**다. ‘최신·최고’가 아니라 저비용 구조화 요약을 검증할 출발점으로 선택한다. API 계정 접근 가능 여부, JSON 구조 준수, 한국어 항목 추출 결과를 확인한 뒤 모델 ID를 고정한다. 모델 페이지의 텍스트 단가는 입력 $0.40/100만 토큰, 출력 $1.60/100만 토큰이다. [GPT-4.1 mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini)

계산 예시: **실제 길이의 추정이 아니라 사용량 가정**으로, 세션의 모든 map/reduce 요청을 합쳐 입력 30,000토큰·출력 6,000토큰이면 $0.012+$0.0096 = **$0.0216**다. 이와 동일한 1시간 세션 20개를 처리한다면 GPT-Transcribe STT $5.40 + 요약 $0.432 = **$5.832**다. 실제 한국어 토큰 수·재시도·검증 요청은 결과 사용량으로 계산한다.

STT만 로컬로 하고 요약은 클라우드로 보내는 경우 텍스트가 외부로 전송된다. 후속 확인한 M1 Pro 16GiB에서는 Qwen3 4B 4bit를 로컬 요약 후보로 평가한다. 8B는 비교 자료로만 남기고 기본 설치하지 않는다. 실제 처리 시간·최종 모델은 미확정이다. 이 분기는 TODO의 L-01 평가 및 조건부 P0 작업이다.

## 6. 비용 산식과 앱 표시 규칙

```text
STT 예상액 = Σ(요청에 포함된 오디오 초 / 60 × 경로별 분당 단가)
요약액 = Σ(청구 입력 토큰 × 입력 단가 + 청구 출력 토큰 × 출력 단가) / 1,000,000
전체액 = STT액 + 요약액 + 사용자가 선택한 추가 기능액
```

두 입력 트랙을 각각 1시간씩 전사하면 요청 길이는 최대 2시간이다. 하나로 섞은 1시간을 한 번 전사하는 방식과 비용이 다르다. 파일 길이, 중복 구간, 요청 간 겹침, 재시도, 전체 재전사를 모두 포함한다. ‘같은 녹음이라 무료 재시도’라고 안내하지 않는다.

가격 스냅샷에는 공급자·모델·전사 경로·옵션·단가·확인일·통화를 저장한다. 최신 가격 확인 전까지 ‘확인일 기준 예상’으로 표시한다. 공급자 사용량이 없으면 추정과 실제를 구별한다. 세션 비용 한도는 발송 전 예약액을 기준으로 다음 요청을 보류하는 장치이며, 공급자 청구를 절대 상한으로 보장하는 장치가 아니다.

## 7. 한국어 벤치마크 계획

### 데이터와 비교 설계

사용 허가된 10분 녹음 6개, 총 60분을 준비한다: 깨끗한 한국어 강의, 전문용어·영문 혼용 강의, 1.5~2배속 강의, 온라인 2인 회의, 잡음 있는 대면 다인 회의, 동시 발화·고유명사·숫자가 많은 회의. 반복·무음·정정 발언은 별도 짧은 회귀 fixture로 추가한다.

사람이 원 음성을 들으며 정답 전사와 중요 개체·결정·담당자·기한을 주석 처리한다. 조정용 40분과 보류 평가용 20분을 나눠 동일 세트에 프롬프트를 과적합하지 않는다. 청크 정책·오디오 코덱·언어 설정을 기록하고 동일 입력으로 비교한다. 요약은 STT와 분리하여 먼저 같은 정답 전사를 입력해 평가한다.

### 지표와 제안 합격선

| 지표 | 측정 방법 | 잠정 기준 |
| --- | --- | --- |
| 한국어 CER | NFC 정규화, 문장부호·공백 제거본의 문자 편집거리/정답 문자 수. 원문·띄어쓰기 포함 수치도 별도 기록 | 깨끗한 강의 ≤10%, 잡음 회의 ≤20% 목표 |
| 핵심 개체 | 이름·제품·수치·날짜의 정확 일치율, 표기 변형 규칙 고정 | ≥95% 목표, 금액·기한 오류 별도 열거 |
| 처리 속도 | RTF=처리 벽시계 시간/오디오 길이, 업로드 포함/제외 분리 | 클라우드 전체 파이프라인 60분 입력→10분 내 목표 |
| 화자 품질 | 화자 기능 선택 시 정답 구간과 DER, 겹침 포함 여부·collar 명시 | 별도 기능 출시 조건, 기본 MVP 합격 조건 아님 |
| 요약 근거성 | 각 사실 항목과 실제 근거 의미의 일치 여부 사람이 확인 | 결정·담당자·기한 환각 0건 |
| 중요 항목 회수 | 정답 주석 중 요약에 정확히 포함된 중요 항목 비율 | ≥90% 목표 |
| 사용성 | 10분 녹음 결과의 사용자가 수행한 교정 시간 | 후보 간 비교, 목표 2분 이하 |
| 로컬 자원 | Mac 모델, OS, RAM, 모델 버전, cold/warm 시간, peak RSS·발열 | 장치별 보고, 보편적 실시간 처리 주장 금지 |

기준은 녹음 난이도에 따라 사용자와 조정할 수 있으나, 시험 후 유리하게 바꾼 경우 변경 이유와 원래 결과를 함께 남긴다. 평균값만으로 어려운 회의의 실패를 숨기지 않는다.

### 문맥 효과 A/B

같은 음성에 (A) 문맥 없음, (B) 강의/회의 이름만, (C) 목적+실제 용어·안건을 넣어 비교한다. CER·개체 일치·없는 용어 삽입을 확인한다. 요약은 동일 전사에 일반 요약과 목적별 스키마를 비교한다. 비용 대비 교정 시간까지 고려해 최종 선택한다.

60분 자료를 GPT-Transcribe·mini·Nova-3 파일 전사에 각각 한 번씩 보내는 단순 STT 예산은 $0.270+$0.180+$0.258 = **$0.708**다. 문맥 A/B, 재시도, 요약, 추가 옵션을 포함한 실제 시험 예산은 별도로 잡는다. 사용자 음성과 API 키 없이 이 시험을 수행한 것처럼 보고하지 않는다.
