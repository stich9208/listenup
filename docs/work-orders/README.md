# 구현 작업지시서

공통 계약은 `Package.swift`와 `Sources/ListenUpDomain`이며 통합 담당만 수정한다. 작업 담당은 자신의 소유 경로만 편집하고, 계약 변경이 필요하면 수정 이유와 필요한 시그니처를 통합 담당에게 전달한다.

WO-001과 WO-002 구현을 통합해 SwiftUI 앱, 로컬 모델 관리, 캡처·재생, 처리, Export 수직 흐름을 만들었다. 저장·오디오·앱·AI는 Astra Low 독립 검수 결과를 반영한다. 최종 판정에는 코드와 테스트 명령뿐 아니라 실제 권한 녹음, 장시간 안정성, Notion 붙여넣기처럼 실기기에서 남은 검증을 분리해 기록한다.
